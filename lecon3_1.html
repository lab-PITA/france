1. 形容詞の位置と基本ルール

・原則として名詞の後に置かれる。
・短い、使用頻度の高い形容詞（grand, petit, beau, vieux等）は名詞の前に置かれる。
・名詞の前に複数形容詞がある場合、不定冠詞の des は de に変わる。

2. 不規則な女性形

語尾変化例
-er → -èreétranger → étrangère
-f → -venaïf → naïve
-x → -seheureux → heureuse
子音を重ねるbon → bonne / gros → grosse
特殊変化blanc → blanche / long → longue

3. 男性単数第2形（母音衝突回避）

母音・無音hで始まる男性単数名詞の前では特殊な形を使う。

通常第2形例
beaubelun bel oiseau
nouveaunouvelun nouvel élève
vieuxvieilun vieil homme

4. 複数形の作り方

ルール例
通常 (+s)petits, grandes
不変 (-s, -x)bas, heureux
-eau/eu (+x)beaux, cheveux
-al → -auxcheval → chevaux
特殊oeil → yeux / monsieur → messieurs
